# Flask Gemini AI Chatbot

Ứng dụng chatbot AI trên nền tảng web, được xây dựng bằng Flask Python và Gemini API.

## Chức năng

- Nhập câu hỏi trên giao diện web.
- Gửi câu hỏi từ trình duyệt tới Flask.
- Kết nối Gemini API.
- Hiển thị câu trả lời của AI.
- Xử lý lỗi khi thiếu nội dung hoặc mất kết nối.

## Công nghệ sử dụng

- Python
- Flask
- HTML
- CSS
- JavaScript
- Gemini API
